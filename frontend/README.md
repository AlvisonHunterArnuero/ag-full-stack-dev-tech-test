# TaskFlow Frontend

The frontend for the Task Management application, built with React, Vite, Material UI, and TailwindCSS.

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 7
- **Styling**: Material UI v6 & TailwindCSS v4
- **State Management**: TanStack Query v5 & React Context
- **Routing**: React Router v6
- **Testing**: Vitest & React Testing Library (Happy DOM)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Testing

Run the unit test suite:

```bash
npm test
```

To run tests in UI mode:

```bash
npx vitest --ui
```

## Features

- **Authentication**: Login and Registration forms with validation.
- **Task Management**: Create, edit, and delete tasks.
- **Dashboard**: Overview of task statistics and paginated task list.
- **Responsive Design**: Premium dark-themed UI that works on all devices.
